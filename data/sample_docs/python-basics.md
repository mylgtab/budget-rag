# Python 与并发

CPython 有全局解释器锁，同一时刻只有一个线程执行字节码。
GIL 让 CPU 密集型多线程无法真正并行，但 IO 阻塞时会释放。
多进程绕开 GIL，每个进程有独立的解释器和内存。
asyncio 是单线程事件循环，靠协程在 IO 等待时切换任务。
协程切换不经过操作系统，开销比线程切换小得多。
await 只能出现在 async 函数里，它把控制权交回事件循环。
asyncio.gather 并发执行多个协程并等待全部完成。
asyncio.create_task 把协程包装成任务，立刻调度但不等结果。
同步阻塞调用会卡死事件循环，需要放进线程池执行。
生成器用 yield 逐次产出值，节省内存。
迭代器协议要求实现 __iter__ 和 __next__。
上下文管理器通过 __enter__ 和 __exit__ 管理资源释放。
装饰器本质是把函数作为参数返回新函数，functools.wraps 保留原信息。
深拷贝递归复制所有嵌套对象，浅拷贝只复制最外层。
Python 的字典在 3.7 之后保证插入顺序。
列表推导式比 for 循环 append 更快，因为省去方法查找。
is 比较对象身份，== 比较值相等。
可变默认参数在函数定义时只创建一次，会导致共享状态。
垃圾回收用引用计数为主，循环引用交给分代回收处理。
GIL 的存在让多线程适合 IO 密集，不适合纯计算。
