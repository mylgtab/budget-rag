# HTTP 缓存

HTTP 缓存用来减少重复请求。响应头里 `Cache-Control` 控制缓存行为，`max-age` 表示资源可以缓存多少秒。

强缓存命中时浏览器不会发请求，直接读本地副本。协商缓存则会带上 `If-None-Match` 或 `If-Modified-Since`，
服务器返回 304 时表示内容没变，可以继续用缓存。

`ETag` 是内容指纹，内容变了 ETag 就变。`Last-Modified` 是最后修改时间，精度只到秒，
所以内容在一秒内多次变化时不太可靠。

常见误区是把 `no-cache` 当成不缓存：它的意思是每次使用前都要向服务器确认。
`no-store` 才是完全不存。
