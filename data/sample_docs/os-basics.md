# 操作系统基础

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。
同一进程内的线程共享地址空间和文件描述符，但每个线程有独立的栈和寄存器。
进程切换需要切换页表，代价比线程切换高。
虚拟内存让每个进程以为自己独占连续的地址空间。
页表把虚拟地址映射到物理地址，TLB 缓存最近的映射结果。
缺页中断发生在访问的页不在物理内存时，由操作系统换入。
LRU 置换策略淘汰最久未使用的页，但实现成本高，实际常用近似算法。
写时复制让 fork 之后父子进程先共享物理页，写入时才真正复制。
用户态和内核态通过系统调用切换，一次切换有固定开销。
自旋锁适合临界区极短的场景，因为不会让出 CPU。
互斥锁在拿不到锁时会让线程睡眠，适合临界区较长的场景。
死锁的四个必要条件是互斥、占有并等待、不可抢占、循环等待。
破坏循环等待最常用的办法是按固定顺序加锁。
银行家算法通过预判安全性避免死锁，但需要提前知道最大需求。
时间片轮转调度让每个就绪进程轮流运行一个时间片。
多级反馈队列根据进程行为动态调整优先级，交互型进程优先。
优先级反转指低优先级进程持有锁导致高优先级进程等待。
优先级继承可以缓解优先级反转，持锁者临时提升到等待者的优先级。
内存映射文件把文件直接映射到地址空间，读写不经过缓冲区拷贝。
缺页率过高会触发频繁换页，形成抖动，吞吐急剧下降。
