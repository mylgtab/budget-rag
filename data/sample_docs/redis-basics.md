# Redis 与缓存

Redis 是单线程处理命令的内存数据库，避免锁竞争。
Redis 的持久化有 RDB 和 AOF 两种方式。
RDB 是某一时刻的全量快照，恢复快但可能丢最后一段数据。
AOF 记录每条写命令，更安全但文件更大。
Redis 4.0 之后支持混合持久化，兼顾两者。
缓存穿透指查询不存在的数据，请求全部打到数据库。
布隆过滤器可以拦截缓存穿透，但只能判断「一定不存在」。
缓存击穿指热点 key 过期瞬间大量请求涌入。
互斥锁或逻辑过期可以缓解缓存击穿。
缓存雪崩指大量 key 同时过期，数据库被打爆。
给过期时间加随机偏移可以缓解缓存雪崩。
Redis 的过期删除采用惰性删除加定期删除。
惰性删除在访问时才发现过期，可能占用内存。
定期删除每秒抽样检查，不会全量扫描。
LRU 近似算法用于内存淘汰，采样若干 key 挑最久未用的。
Redis 的分布式锁用 SET NX EX 实现，必须设置过期时间防死锁。
释放分布式锁要用 Lua 脚本校验持有者，避免误删别人的锁。
主从复制是异步的，主节点故障可能丢数据。
哨兵模式负责故障转移，但同一时刻只有一个主。
集群模式按槽位分片，支持水平扩容。
