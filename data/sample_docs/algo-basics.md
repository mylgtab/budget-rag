# 算法与数据结构

快速排序平均时间复杂度是 O(nlogn)，最坏在已排序数组上退化为 O(n²)。
快速排序的平均空间复杂度是 O(logn)，来自递归栈。
归并排序稳定，时间复杂度稳定在 O(nlogn)，但需要 O(n) 额外空间。
堆排序原地进行，时间复杂度 O(nlogn)，但不稳定。
稳定排序保证相等元素的相对顺序不变。
比较排序的下界是 O(nlogn)，由决策树模型证明。
计数排序适合取值范围小的整数，时间复杂度 O(n+k)。
二分查找要求序列有序，时间复杂度 O(logn)。
哈希表平均查找 O(1)，冲突严重时退化。
开放寻址法把冲突元素放到下一个空槽，链表法则在同一槽挂链。
哈希表的负载因子过高会触发扩容，扩容需要重新散列。
布隆过滤器判断元素是否存在，有假阳性但没有假阴性。
并查集支持合并与查询连通性，路径压缩后接近常数时间。
拓扑排序只适用于有向无环图，可用于任务依赖排序。
Dijkstra 不能处理负权边，负权要用 Bellman-Ford。
最小生成树常用 Prim 和 Kruskal，两者都基于贪心。
动态规划要求最优子结构，且子问题有重叠。
贪心算法要求每一步的局部最优能推出全局最优。
回溯通过剪枝减少搜索空间，常用于组合与排列问题。
B 树降低树高以减少磁盘 IO，B+ 树把数据都放在叶子并串成链表。
