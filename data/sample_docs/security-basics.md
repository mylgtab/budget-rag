# Web 安全

XSS 指攻击者把脚本注入页面并在受害者浏览器执行。
存储型 XSS 的恶意脚本存在数据库里，影响面大。
反射型 XSS 通过 URL 参数注入，需要诱导点击。
防御 XSS 的核心是输出转义，而不是输入过滤。
内容安全策略 CSP 可以限制脚本来源，是纵深防御。
CSRF 利用浏览器自动携带 Cookie 的特性伪造请求。
防御 CSRF 用 SameSite Cookie 或 CSRF Token。
SQL 注入源于拼接字符串，应使用参数化查询。
最小权限原则要求数据库账号只给必要权限。
密码存储必须加盐哈希，不能用明文或单纯 MD5。
bcrypt 和 argon2 是推荐的密码哈希算法。
HTTPS 保证传输加密与身份认证。
HSTS 强制浏览器使用 HTTPS，防止降级。
证书要与域名匹配，通配符证书只覆盖一级子域。
越权分为水平越权和垂直越权。
水平越权是访问同级别其他用户的数据。
垂直越权是低权限用户执行高权限操作。
防御越权要在服务端校验资源归属，不能只靠前端隐藏。
敏感信息不要写进日志，避免二次泄漏。
依赖漏洞要定期扫描，旧版本常常是突破口。
