# 机器学习基础

过拟合指模型在训练集表现好、测试集差。
正则化通过惩罚参数大小抑制过拟合。
L1 正则产生稀疏解，L2 让参数更平滑。
交叉验证把数据分成 K 份，轮流验证，降低评估方差。
留出法简单但结果依赖单次划分。
数据泄漏指测试信息进入训练，会让指标虚高。
类别不平衡时准确率会误导，应看精确率和召回率。
精确率是预测为正里真正为正的比例。
召回率是真正为正里被找出来的比例。
F1 是精确率和召回率的调和平均。
AUC 衡量排序能力，与阈值无关。
学习率过大会震荡，过小会收敛慢。
批归一化让各层输入分布稳定，加速收敛。
Dropout 在训练时随机失活，起正则作用。
梯度消失可用残差连接或换激活函数缓解。
批量大小会影响收敛速度和泛化。
早停根据验证集表现停止训练，防止过拟合。
特征缩放对距离敏感的模型很重要。
混淆矩阵能看出错误集中在哪一类。
评估指标要和业务目标一致，不能只看准确率。
