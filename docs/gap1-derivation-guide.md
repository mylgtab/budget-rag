# 空位 1 推导路线（写给作者本人看的，不是论文）

> 目标：把「用分数间隔决定取几块」从**经验技巧**变成**一个有前提、有边界、可被证伪**的结论。
> 你不需要证一个惊天大定理；你需要交出一份**说得清、站得住、经得起追问**的理论小注。

---

## 0. 先用一句话说清你在干什么

检索器给每道题排出一串块，分数是 `s1 ≥ s2 ≥ s3 ≥ ...`。
我们用 `γ = (s1 − s2) / s1` 当「这道题难不难」的代理：γ 大 → 有把握 → 少取；γ 小 → 没把握 → 多取。

**你要回答的问题是：凭什么 γ 能代表难度？**

现在的论文只能说「实验上它管用，而且省 11%–20% 上下文」。审稿人会问：

> 「γ 只是 top1 和 top2 的差，它凭什么预测『再取一块有没有用』？换一个数据集还成立吗？什么时候不成立？」

**你的任务不是让质疑消失，而是给它一个明确的答案**：在最弱的假设下，γ 能推出什么；在什么条件下会失效。

## 1. 先把「边际收益」写成数学

这是整件事的地基，写不出来后面都免谈。

### 1.1 定义符号（照着抄进笔记）

- 一道题 q，检索器给出块序列 `c1, c2, ..., cK`，分数 `s1 ≥ ... ≥ sK`
- 取前 k 块，记上下文 `S_k = {c1, ..., ck}`
- 质量函数 `Q(S_k)`：前 k 块里**有答案**的概率（就是你的 recall@k）
- 边际收益：`Δ_k = Q(S_{k+1}) − Q(S_k)`，即「再多取一块，命中概率涨多少」

### 1.2 你要证的东西（一句话版）

> `Δ_k` 随 γ 单调递减。

注意：**不是**「Δ_k 小」，而是「γ 大时 Δ_k 小」。这是**两个量之间的单调关系**，不是绝对值。

### 1.3 用你自己的数据把它画出来

| γ 分箱 | k=4 召回 | k=10 召回 | Δ |
|---|---|---|---|
| Q1（γ≤0.023） | 0.760 | 0.853 | 0.093 |
| Q2 | 0.840 | 0.907 | 0.067 |
| Q3 | 0.880 | 0.893 | 0.013 |
| Q4（γ>0.117） | 0.974 | 0.987 | 0.013 |

这张表就是你要解释的对象：**为什么 γ 越大，Δ 越小？**

## 2. 三个命题，从易到难（选一个做主结果，其余当补充）

### 命题 A（最弱，但一定写得出来）

> **在「分数是效用的单调变换」假设下，γ 与 Δ 负相关。**

- 假设：存在潜在效用 `u_i`，排序分数 `s_i = f(u_i)`，f 单调递增
- 要证：γ 大的题，其「下一块有用」的概率不高于 γ 小的题
- 用到的工具：**只有**条件期望与单调性，不需要概率模型
- 难度：★☆☆☆☆（一周内能写完）
- 价值：给「γ 是难度代理」一个最紧的合法说法

### 命题 B（中等，最有性价比）★ 推荐主结果

> **在 Plackett–Luce 模型下，`Δ_k` 是 γ 的单调递减函数。**

Plackett–Luce 是最常用的「从效用生成排序」的模型：

```
P(排序 = c1, c2, ..., cK) = ∏_k  exp(u_{c_k}) / Σ_{j≥k} exp(u_{c_j})
```

也就是：每一步按 `exp(u)` 加权抽一个，抽走的移除。

要做的事：
1. 设每块有一个「被需要的概率」 `p_i`（这道题要 i 块才答对的概率），且 `p_i` 随 i 递减
2. 在 PL 下，`s1 − s2` 的大小与「`p1` 接近 1」相关
3. 推出：γ 越大 → `p1` 越接近 1 → 再加一块的增益 `p2 + p3 + ...` 越小
4. 形式化：`Δ_k(γ)` 对 γ 单调不增

- 难度：★★★☆☆（要一点概率推导，2–3 周）
- 价值：**这就是审稿人想看到的「有模型、有单调性、有解释」**
- 卡点：PL 里「一块被需要」怎么定义，需要你补一个「答案位置先验」

### 命题 C（最强，但可能证不出来）

> **阈值策略的次优性 ≤ ε(γ 的分布)。**

即：对任意预算 B，按 γ 设阈值的策略，其召回与「最优策略」差不超过 ε。

- 难度：★★★★★（需要 submodularity + 近似比，容易卡住）
- 建议：**别一上来做这个**；做成 B 之后，如果时间够，再补一个「在什么条件下 C 成立」的讨论

## 5. 每晚 30 分钟的具体做法（照做即可）

### 第 1 晚：只做定义页

- 写出 `Q(S_k)` 的严格定义（用「事件」的语言：`E_k = {答案在 S_k 中}`）
- 写出 `Δ_k = P(E_{k+1}) − P(E_k)`
- 写出 `γ` 的表达式
- **自检**：能不能用一句话向非本专业的人解释「Δ_k 是什么」？

### 第 2–5 晚：把 PL 模型抄一遍并理解

- 抄写 PL 公式，手算一个 3 块的小例子（自己编 u 值）
- 算出 `P(c1 排第一)`、`P(c2 排第一)`，看 `s1 − s2` 与什么有关
- **自检**：能不能不用公式、只用文字说出「PL 下的分数差意味着什么」？

## 6. 常见卡点（提前告诉你）

| 卡点 | 表现 | 怎么办 |
|---|---|---|
| 「效用」是什么 | 想不清 u_i 指什么 | 定义成「这块含答案的概率的对数」即可，别追求哲学 |
| 分数不是概率 | s 是余弦相似度，不是概率 | 用单调变换 f 桥接，或直接假设「s 排序 = u 排序」 |
| 条件期望写不动 | E[Δ | γ] 展开后一堆符号 | 先固定 γ 的区间（分箱），在箱内做，别追求连续形式 |
| 想一步到位 | 想做命题 C | 停。先交 B，C 留给「未来工作」 |
| 证明太丑 | 觉得自己写得不漂亮 | 丑没关系，**只要每步有理由**；论文里的理论附录本来就丑 |

## 7. 最后：怎么判断自己「真的懂了」

三个自检问题，能答上来就算过关：

1. **不用公式**，向一个没学过检索的人解释：为什么「第一名和第二名分数差得远」意味着「不用再取更多块」？
2. 如果我把 γ 的定义改成 `s1 / s2`（比值而不是相对差），命题 B 还成立吗？为什么？
3. arguana 上为什么失效？失效的是**模型假设**还是**我们的方法**？

能答 1 和 3，这篇理论就立住了；能答 2，说明你真的摸到了结构。
