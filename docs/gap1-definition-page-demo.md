# 定义页（示范版）——照这个格式写你自己的

> 用途：交第 1 晚的作业。目标不是好看，是**每一个符号都说得清**。
> 你可以把下面的数字和句子换成自己的理解，但结构别动。

---

## 1. 一句话说明这一页在干什么

本文要回答：**用 top-1 与 top-2 的相对分数差 γ 作为「这道题难不难」的代理，在什么条件下是合理的？**
本页只做一件事：把后面证明要用到的对象**定义清楚**，并写出待证命题的准确陈述。本页不含任何证明。

---

## 2. 符号

| 符号 | 含义 | 备注 |
|---|---|---|
| `q` | 一道问题 | 固定任意一道 |
| `c_1, …, c_K` | 检索器返回的候选块，按分数降序 | 只看前 K 块 |
| `s_1 ≥ s_2 ≥ … ≥ s_K` | 对应检索分数 | 余弦相似度或融合分，非概率 |
| `S_k = {c_1, …, c_k}` | 取前 k 块构成的上下文 | `S_0 = ∅` |
| `k` | 取几块（整数） | 本文的决策变量 |
| `γ = (s_1 − s_2) / s_1` | 归一化间隔 | 要求 `s_1 > 0`，否则约定 γ = 0 |
| `E_k` | 事件「答案片段出现在 `S_k` 中」 | 二值：发生 / 不发生 |
| `Q(S_k) = P(E_k)` | 取 k 块时的质量 | 就是评测里的 recall@k |
| `Δ_k = Q(S_{k+1}) − Q(S_k)` | 第 k+1 块的边际收益 | 本文的预测目标 |

**一句话自检**：`Δ_k` 是「再多取一块，答案被覆盖的概率涨多少」。不是「多取一块多花多少 token」。

---

## 3. 质量函数

文中「质量」一律指**答案覆盖**，即

```
Q(S_k) = P(E_k),    E_k = {存在 i ≤ k，使 c_i 含有答案片段}
```

用补事件写更便于计算：

```
1 − Q(S_k) = P(答案不在前 k 块中) = P(E_1^c ∩ E_2^c ∩ … ∩ E_k^c)
```

若假设「答案落在第 i 块」与块的选择独立，记 `p_i = P(答案落在第 i 块 | 前 i−1 块都没有)`
（即已知前 i−1 块没有时，第 i 块含答案的条件概率），则

```
Q(S_k) = 1 − ∏_{i=1}^{k} (1 − p_i)
Δ_k    = Q(S_k) · p_{k+1}      ... (⋆)
```

**(⋆) 是这个定义页最有用的产物**：它把「边际收益」化成「当前质量 × 下一块的条件命中概率」。
后面命题 B 的证明就是从这里出发的。

> 自检：如果 p 全部相等，Δ_k 会怎么变？为什么？（答案：Δ_k 递减，因为 Q(S_k) 递增而 p 不变，乘积先增后减？——不对，Δ_k = Q_k · p 是递增的。这说明「p 相等」不足以推出递减，必须假设 p_i 递减。**这个反推很有用，写进你的笔记。**）

---

## 4. 间隔

```
γ = (s_1 − s_2) / s_1 = 1 − s_2 / s_1
```

- γ → 1：第二名远落后于第一名 → 「第一名几乎确定是对的」
- γ → 0：两名接近 → 「分不清谁是答案」

用「分不清」这个词而不是「难」，是故意的：γ 描述的是**分布上的确定性**，不是题目本身的客观难度。

## 5. 待证命题（B 的陈述）

**假设 A1（分数排序 = 效用排序）**：存在潜在效用 `u_i` 与严格单调递增函数 `f`，使 `s_i = f(u_i)`；
且「块越有用，越靠前」。本文只用到**排序**，不用到具体数值。

**假设 A2（答案位置先验递减）**：条件命中概率 `p_1 ≥ p_2 ≥ … ≥ p_K`，即「第 i 块含答案」的可信度随名次递减。

**命题 B'（单调性）**：在 A1、A2 下，对任意 `k ≥ 1`，`Δ_k` 关于 γ **单调不增**。即

```
若 γ(q) ≥ γ(q')，则 Δ_k(q) ≤ Δ_k(q')，对一切 k。
```

（这里比较的是两道题 q、q'；同一道题内部的 k 由 A2 保证递减。）

**注**：这是命题 B 的**先导版本**，只谈「跨题比较」；完整版还要给出 `Δ_k` 关于 k 的递减率与 γ 的显式关系。
先把这一版证出来，再增强。

## 6. 这个命题不声称什么（重要）

1. **不声称** γ 是充分统计量：γ 相同、Δ_k 仍可能不同（箱内方差）。
2. **不声称** 结论对任意检索器成立：A1 被打破时（对抗构造语料），单调性可以反转。
3. **不声称** 阈值策略最优：那是命题 C，本文不做。

## 7. 一个手算的小例子（写作业时一定要有）

设某题的三块条件命中概率为 `p_1 = 0.90, p_2 = 0.06, p_3 = 0.02`。

- `Q(S_1) = 0.90`，`Q(S_2) = 0.90 + 0.10×0.06 = 0.906`，`Q(S_3) = 0.906 + 0.094×0.02 ≈ 0.9079`
- `Δ_1 = 0.006`，`Δ_2 ≈ 0.0019` —— **递减**，符合 A2

现在换一道「没把握」的题：`p_1 = 0.60, p_2 = 0.25, p_3 = 0.10`。

- `Q(S_1) = 0.60`，`Q(S_2) = 0.70`，`Q(S_3) = 0.73`
- `Δ_1 = 0.10`，`Δ_2 = 0.03`

**对比**：第一题 `p_1` 高（对应 γ 大），`Δ_1 = 0.006`；第二题 `p_1` 低（γ 小），`Δ_1 = 0.10`。
这就是命题 B' 想一般化的现象：**γ 大 → p_1 大 → Δ 小**。

> 自检：如果你想反驳「p_1 大 ⇒ Δ_1 小」，构造一个反例需要动哪个量？（提示：动 `p_2`，让第一题的 p_2 也很大。）
