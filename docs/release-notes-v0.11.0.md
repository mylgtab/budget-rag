## 这是为 SCI 补的那一层

把「级联检索」写成**带预算约束的子模最大化问题**：

```
max Q(S)  s.t.  Σ c(a) ≤ B
```

- **命题 1**：质量函数在边际收益递减假设下单调子模 → 按「边际收益/成本」贪心可获 1−1/e 近似
- **命题 2**：改写门控的最优形式是「p·Δq > λ·c」→ 阈值随预算影子价格移动
- **命题 3**：级联的最优策略是一条置信度阈值链
