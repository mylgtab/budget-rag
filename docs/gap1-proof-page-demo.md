# 证明页（示范版）——照这个格式写你自己的

> 用途：定义页之后的第二份作业。目标不是长，是**每一步都有理由、每条假设都有对应**。
> 建议只完整证 `k = 1` 的情形，`k ≥ 2` 写成猜想 + 数值支持。**不要硬证一般情形。**

---

## 1. 一句话说明这一页在干什么

本文要证明：**在什么假设下，归一化间隔 γ 越大，下一块能带来的增益 Δ 越小。**
定义页已经把 `Q(S_k)`、`Δ_k`、`γ`、`p_i` 定义清楚，本页不再重复，只引用。
本页给出两个引理、一个定理（限 k = 1）、一个反例，以及一处适用边界。

---

## 2. 记号（从定义页沿用）

| 符号 | 含义 |
|---|---|
| `p_i` | 已知前 i−1 块都没答案时，第 i 块含答案的条件概率 |
| `Q(S_k)` | 取前 k 块时答案被覆盖的概率，`Q(S_k) = 1 − ∏_{i≤k}(1−p_i)` |
| `Δ_k` | 第 k+1 块的边际收益，`Δ_k = Q(S_{k+1}) − Q(S_k)` |
| `γ` | 归一化间隔，`γ = (s₁ − s₂)/s₁` |

---

## 3. 引理 1（(⋆) 式）

**陈述**：在定义页的独立性假设下，

```
Q(S_k) = 1 − ∏_{i=1}^{k} (1 − p_i)
Δ_k    = (1 − Q(S_k)) · p_{k+1}
```

**证明**：

```
1 − Q(S_k) = P(答案不在前 k 块中) = ∏_{i=1}^{k} (1 − p_i)          （独立性）
Δ_k = [1 − ∏_{i=1}^{k+1}(1−p_i)] − [1 − ∏_{i=1}^{k}(1−p_i)]
    = ∏_{i=1}^{k}(1−p_i) · p_{k+1}
    = (1 − Q(S_k)) · p_{k+1}                                        ∎
```

**一句话解释**：增益只能来自「尚未被覆盖的那部分」，所以系数是 `1−Q`，不是 `Q`。

---

## 4. 引理 2（同一道题内部，Δ_k 随 k 递减）

**陈述**：若 `p_1 ≥ p_2 ≥ … ≥ p_K`（定义页的 A2），则对同一道题，`Δ_k` 关于 k 递减。

**证明**：

```
Δ_k     = ∏_{i=1}^{k}(1−p_i) · p_{k+1}
Δ_{k+1} = ∏_{i=1}^{k+1}(1−p_i) · p_{k+2}

Δ_{k+1} / Δ_k = (1 − p_{k+1}) · p_{k+2} / p_{k+1}  ≤ 1
```

因为 `p_{k+2} ≤ p_{k+1}`（A2）且 `1 − p_{k+1} ≤ 1`，比值 ≤ 1，故 `Δ_{k+1} ≤ Δ_k`。∎

**注意**：这条引理**没有用到 γ**。它只说明「取越多越不划算」，是题干内部的事。

---

## 5. 定理（跨题比较，k = 1）

### 5.1 先看清障碍

由引理 1，取 k = 1：

```
Δ_1 = (1 − p_1) · p_2 = ρ · p_1(1 − p_1) ，   其中 ρ := p_2 / p_1
```

**这个式子说明**：「γ 大 ⇒ Δ 小」不只取决于 p₁，还取决于**尾部相对质量 ρ**。
只假设「ρ₁ = g(γ) 递增」是**不够**的——ρ 若随 p₁ 一起变厚，Δ₁ 可能反弹。

### 5.2 定理陈述

**假设**：

- **A1**（分数排序 = 效用排序）
- **A3**（间隔与把握度的桥接）：存在单调递增 `g`，使 `p_1 = g(γ)`
- **H1**（高把握区）：`p_1 ≥ 1/2`
- **H2**（尾部不变厚）：`ρ = p_2/p_1` 关于 `p_1` 单调不增

**结论**：在 A1、A3、H1、H2 下，`Δ_1` 关于 γ 单调不增。

### 5.3 证明（离散版，四步，不用求导）

设两道题 q 与 q'，且 `p_1(q) ≤ p_1(q')`（即 γ(q) ≤ γ(q')，由 A3），两者都 ≥ 1/2。

**第一步**：由 H2，`ρ(q') ≤ ρ(q)`。

**第二步**：写差

```
Δ_1(q') − Δ_1(q) = ρ(q')·h(p_1(q')) − ρ(q)·h(p_1(q)) ，   h(p) := p(1−p)
```

**第三步**：因为 `ρ(q') ≤ ρ(q)` 且 `ρ ≥ 0`，放缩

```
Δ_1(q') − Δ_1(q) ≤ ρ(q) · [ h(p_1(q')) − h(p_1(q)) ]
```

**第四步**：`h(p) = p(1−p)` 在 `[1/2, 1]` 上单调递减（因为 `h'(p) = 1−2p ≤ 0`），
故 `h(p_1(q')) ≤ h(p_1(q))`，右端 ≤ 0。

合并：`Δ_1(q') ≤ Δ_1(q)`，即 γ 大的题 Δ 不更大。∎

### 5.4 这个定理在各个情形下说什么

| 情形 | 结论 |
|---|---|
| 高把握区、尾部不变厚 | γ 大 ⇒ Δ 小（定理成立） |
| 低把握区（p₁ < 1/2） | **不成立**，见 §6 反例 |
| 对抗语料（尾部相对变厚） | **不成立**，H2 被打破，见 §7 |

---

## 6. 反例（说明 A1+A3 不够，半页）

取最简单的模型：让每块的条件命中概率**相同**，`p_i ≡ θ`。则

```
p_1 = θ ,  p_2 = θ ,  ρ = 1
Δ_1 = θ(1 − θ) ,      dΔ_1/dθ = 1 − 2θ
```

代入几个值：

| θ（≈ 把握度） | Δ₁ = θ(1−θ) |
|---|---|
| 0.20 | 0.160 |
| 0.30 | 0.210 |
| 0.40 | 0.240 |
| **0.50** | **0.250（最大）** |
| 0.60 | 0.240 |
| 0.70 | 0.210 |
| 0.80 | 0.160 |

**结论**：θ < 1/2 时，把握度越高，Δ₁ 反而越大——与定理结论相反。
直到 θ ≥ 1/2 才转为递减。**这就是 H1 必须存在的理由。**

**必须老实说明的一点**：这个反例里 `p_i` 是常数，**不满足 A2**。
所以它只证明「A1+A3 不足」，**不**证明「A1+A2+A3 不足」。
后者需要构造一个 `p_i` 递减、但 `ρ` 随 p₁ 变厚的序列——这是 §9 留给你的问题。

---

## 7. 边界（哪些现实情况让定理失效）

| 假设 | 失效时会发生什么 | 现实对应 |
|---|---|---|
| H1（p₁ ≥ 1/2） | 低把握区里关系反转 | 很难的题，分数差很小 |
| H2（尾部不变厚） | 尾部一起变厚，Δ 反弹 | **对抗构造语料**（arguana）：文档被改写到与问题高度相似 |
| A1（排序=效用） | 分数不再反映真实效用 | 同上；也是 arguana 上自适应「越调越费」的原因 |

**这与实验对得上**：6.18 的四分位表里，Q4（γ 大、p₁≈0.97）的 Δ 是 0.013，
Q1（γ 小）的 Δ 是 0.093——**正是高把握区的表现**。

## 8. k ≥ 2 的推广（写成猜想，不要硬证）

**猜想**：若对每个 j 都有 `ρ_j := p_{j+1}/p_j` 关于 p₁ 单调不增，且 `p_1 ≥ 1/2`，
则 `Δ_k` 关于 γ 单调不增，对一切 k。

**当前支持**：6.18 的数值（0.093 → 0.067 → 0.013 → 0.013 单调递减）。
**为什么不当定理写**：k ≥ 2 时 `Δ_k = ∏_{i≤k}(1−p_i)·p_{k+1}` 涉及多个 `ρ_j` 的联合条件，
逐一验证比较繁琐。写成猜想 + 数值支持，比写一个错证明更诚实。

## 9. 反例 2：H2 是本质条件（能构造，而且很干净）

**问题**：能否构造一个 `p_i` **递减**（满足 A2）、但 `ρ = p₂/p₁` 随 `p₁` **递增**的序列，
使 `Δ₁` 仍然随把握度递增？

**答案：能。** 取

```
p_1 = θ ,   p_2 = θ² ,   p_3 = p_4 = … = 0      （0 < θ < 1）
```

逐条核对：

| 条件 | 是否满足 |
|---|---|
| A1（排序=效用） | 满足：θ 单调增对应 γ 单调增 |
| A2（p 递减） | 满足：`p_2 = θ² ≤ θ = p_1` |
| A3（p₁ = g(γ)） | 满足：取 g 为恒等映射 |
| H1（p₁ ≥ 1/2） | 取 θ ∈ [1/2, 2/3) 时满足 |
| **H2（ρ 不增）** | **不满足**：`ρ = p₂/p₁ = θ`，随 p₁ 递增 |

算 `Δ_1`：

```
Δ_1 = (1 − p_1) · p_2 = (1 − θ) · θ²
dΔ_1/dθ = 2θ(1−θ) − θ² = θ(2 − 3θ)
```

**θ < 2/3 时导数为正**——把握度越高，Δ₁ 反而越大，定理结论不成立。

**结论**：即使 A1、A2、A3、H1 全满足，只要 H2 被打破，结论就失败。
**H2 不是凑数的假设，是本质条件。** 这一段写进证明页，定理的分量立刻不一样。

## 10. 三个自检问题

**问题 1**：定理里 H1、H2 各自对应什么现实情况？

> 合格答案：H1 对应「只在高把握区讨论」，即分数差明显时才谈得上「有把握」；
> H2 对应「尾部不会因为头部更确定而相对变厚」，自然语料成立，对抗构造语料不成立。

**问题 2**：如果去掉 H2 会怎样？

> 合格答案：会出反例。可以设想 ρ 随 p₁ 增大而增大，此时 `Δ₁ = ρ·p₁(1−p₁)` 中
> 第一项是正的（ρ 涨），第二项是负的（h 降），净效果可能为正 → 结论不成立。

**问题 3**：定理在 arguana 上失效，失效的是哪条假设？

> 合格答案：**H2（以及 A1）**。对抗构造让高分块不再是「真含答案」，ρ 随相似度一起涨，
> 于是 `Δ₁` 不再随 γ 下降。这说明失效来自**模型假设**，不是方法本身。
