# 北大 11408 备考总规划（2026-10-27 → 2027-12-26）

> 目标：北京大学，11408（政治 + 英语一 + 数学一 + 408）。
> 初试：2027 年 12 月下旬（约 14 个月）。
> 原则：**每天可验证、每周可复盘、每月可校准**。计划可以调，节奏不能断。

---

## 一、先说实话：这个目标的难度在哪

| 项 | 现实 |
|---|---|
| 北大 11408 | 全国最难档之一，计算机学院/软微/深研院都用 408 |
| 复试线 | 近年常在 350–380，实际录取多在 380–410 |
| 你的短板 | 跨校、双非背景、数学一要补；这些在**初试分数**面前权重很小 |
| 你的优势 | 有工程实操（Docker/K8s/Redis 系统层理解）、能啃文档、上手快 |
| 结论 | **可行，但没有容错空间**：数学一和 408 必须双高（各 120+） |

**一句话**：初试分数是唯一硬通货，复试再谈背景。**把 14 个月变成 2500 小时有效学习。**

## 三、六个阶段（按日期）

### 阶段 0：启动（2026-10-27 → 2026-11-30，5 周）
- 数学：高数上册（极限、导数、积分）第一轮，配基础班视频 + 课后题
- 英语：单词每天 100（新 50 + 复 50），长难句每天 2 句
- 408：数据结构（线性表、栈队列、树）
- 目标：**建立作息**，不追求速度

### 阶段 1：基础一轮（2026-12 → 2027-02，寒假结束）
- 数学：高数下册 + 线代 + 概率，第一轮过完
- 408：数据结构完 + 计算机组成原理开始
- 英语：单词二轮 + 真题阅读（2005–2010）精读
- 政治：**不开始**

### 阶段 2：强化上半（2027-03 → 2027-05）
- 数学：强化课 + 660/1000 题（高数）
- 408：组成原理完 + 操作系统
- 英语：真题阅读 2011–2015
- 每月一次限时小测（数学 2h）

### 阶段 3：暑假攻坚（2027-06 → 2027-08）
- 数学：强化二轮 + 线代概率强化 + 错题本
- 408：计算机网络 + 四门串讲第一遍
- 英语：真题阅读 2016–2020 + 翻译
- 政治：马原 + 史纲（每天 40 分钟）
- **这是胜负手**：暑假每天 9–10 小时

### 阶段 4：真题一轮（2027-09 → 2027-10）
- 数学：真题 2005–2020（限时 3h，周末）
- 408：真题 2009–2020（限时 3h）
- 英语：真题二刷 + 作文模板开始
- 政治：选择题刷 1000 题

### 阶段 5：冲刺（2027-11 → 2027-12-26）
- 数学：真题 2021–2027 + 模拟卷（李林/张宇），错题三刷
- 408：真题二刷 + 王道模拟
- 英语：作文背诵 + 真题三刷（只做错题）
- 政治：肖八肖四 + 大题背诵
- 12 月：**只做三件事**——真题、错题、背诵

## 四、每周节奏（固定）

| 时段 | 内容 |
|---|---|
| 周一–周六 | 数学 3h + 408 3h + 英语 1.5h + 政治 0.5h（阶段 3 起） |
| 周日上午 | 限时小测（数学或 408，交替） |
| 周日下午 | 错题整理 + 本周复盘（30 分钟，跟本鲸对） |
| 周日晚 | 休息或轻量（单词） |

**总时长**：工作日 8h × 6 + 周日 4h ≈ **52h/周**（阶段 0–1 可降到 40h 起步）

## 五、每日检验机制（5 分钟）

每天睡前发给本鲸 4 行：

```
1. 有效学习：X 小时（番茄 Y 个）
2. 今天完成：数学《》第 X 页；408《》第 X 章；英语 X 篇；政治 X
3. 明天第一件事：（一句话）
4. 随机抽问：今天学的一个知识点，用 3 句讲清楚（本鲸会追问）
```

本鲸会做三件事：
- 记进 `daily-log.md`
- 偏离计划超过 3 天 → 提醒
- 每周日出一份周报：时长趋势、完成率、下周调整
