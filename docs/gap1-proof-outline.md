# 证明页（3–4 页）写作骨架

> 承接定义页。目标：把「γ 大 ⇒ Δ 小」从一句断言，变成**有假设、有证明、有反例、有适用边界**的结论。
> 建议只完整证 `k = 1` 的情形，`k ≥ 2` 作为猜想 + 数值支持。**不要硬证一般情形**，会卡死。

## 〇、开篇一段（半页）

交代三件事：

1. 定义页已把 `Q(S_k)`、`Δ_k`、`γ`、`p_i` 定义清楚（引用即可，不重复）
2. 本节要证：在什么假设下，`Δ_k` 关于 γ 单调不增
3. 本节会给出：两个引理、一个定理（k=1）、一个反例、一处边界

---

## 一、引理 1：(⋆) 式的严格化（半页，最容易）

**陈述**：在定义页的独立性假设下，

```
Q(S_k) = 1 − ∏_{i=1}^{k}(1 − p_i)
Δ_k    = (1 − Q(S_k)) · p_{k+1}
```

**证明**（三步，照抄即可）：

```
1 − Q(S_k) = P(答案不在前 k 块中) = ∏_{i=1}^{k}(1 − p_i)        （独立性）
Q(S_{k+1}) − Q(S_k) = [1 − ∏_{i=1}^{k+1}(1−p_i)] − [1 − ∏_{i=1}^{k}(1−p_i)]
                    = ∏_{i=1}^{k}(1−p_i) · p_{k+1}
                    = (1 − Q(S_k)) · p_{k+1}                    ∎
```

**检查点**：能不能一句话解释「为什么是 (1−Q) 而不是 Q」？→「增益只能来自尚未覆盖的部分」。

---

## 二、引理 2：同一题内部，Δ_k 随 k 递减（半页）

**陈述**：若 `p_i` 递减（A2），则对任意题，`Δ_k` 关于 k 递减。

**证明**：

```
Δ_k = ∏_{i=1}^{k}(1−p_i) · p_{k+1}
Δ_{k+1}/Δ_k = [(1−p_{k+1}) · p_{k+2}] / p_{k+1}
```

因为 `p_{k+2} ≤ p_{k+1}` 且 `1−p_{k+1} ≤ 1`，所以比值 ≤ 1，即 `Δ_{k+1} ≤ Δ_k`。∎

**注**：这里其实只用到了 A2 的递减性，**没有用到 γ**。跨题比较才需要 γ。

---

## 三、定理（k = 1 的跨题比较）——本节主结果（1.5 页）

**先看清障碍**。由 (⋆)：

```
Δ_1 = (1 − p_1) · p_2 = ρ · p_1 (1 − p_1) ，   其中 ρ := p_2 / p_1
```

这个式子说明：**「γ 大 ⇒ Δ 小」不只取决于 p₁，还取决于尾部相对质量 ρ**。
只假设「p₁ = g(γ) 递增」是**不够**的——ρ 若随 p₁ 一起涨，Δ₁ 可能反弹。

**陈述**：设 A1、A3 成立，并额外假设

```
(H1) p_1 ≥ 1/2            （高把握区）
(H2) ρ = p_2/p_1 关于 p_1 单调不增   （尾部质量相对头部不涨）
```

则 `Δ_1` 关于 γ 单调不增。

**证明**（4 行）：

```
Δ_1(p_1) = ρ(p_1) · p_1(1 − p_1)
dΔ_1/dp_1 = ρ'(p_1) · p_1(1−p_1) + ρ(p_1) · (1 − 2p_1)
```

- 第一项：`p_1(1−p_1) ≥ 0`，由 H2 得 `ρ' ≤ 0`，故第一项 ≤ 0
- 第二项：由 H1 得 `1 − 2p_1 ≤ 0`，且 `ρ ≥ 0`，故第二项 ≤ 0

两项皆非正 ⇒ `dΔ_1/dp_1 ≤ 0`。再由 A3（`p_1 = g(γ)` 递增）得 `Δ_1` 关于 γ 不增。∎

**这就是你要的定理。** 它干净、可检查，而且 H1/H2 都能对应现实：
- H1：只在高把握区成立（数据里 Q4 的 p₁≈0.97，正在此区）
- H2：尾部不会相对变厚（自然语料成立；对抗语料不成立 → arguana）

## 四、反例（半页，必写）

**反例 1（说明 A1+A3 不够）**：取 `p_i ≡ θ`（常数），则

```
Δ_1 = θ(1−θ),    dΔ_1/dθ = 1 − 2θ
```

θ < 1/2 时 Δ₁ 随 θ **递增**，与结论相反。

**但要老实说明**：这个反例**不满足 A2**（p 不递减）。所以它只证明「A1+A3 不足」，
**不**证明「A1+A2+A3 不足」。

**留给你的问题（也可以不做）**：能否构造一个 `p_i` 递减、但 `ρ` 随 p₁ 递增的序列，
使 A1+A2+A3 仍不足？——如果能，你的定理里的 H2 就是**本质条件**，价值更高。

## 五、边界讨论（半页）

1. **H1 何时失效**：题目很难（p₁ 低）时，γ 与 Δ 的关系可能反转。
2. **H2 何时失效**：分数不再反映真实效用时（对抗构造语料），ρ 会随相似度一起涨。
   arguana 上自适应每个配置都更费 token，正是 H2 被打破的可观测后果。
3. **k ≥ 2 的推广**：`Δ_k = (1−p_1)…(1−p_k)·p_{k+1}`，需要 `ρ_k := p_{k+1}/p_k` 的条件；
   本文未证，只给数值支持（6.18 的四分位表：0.093 → 0.067 → 0.013 → 0.013）。

## 七、写的时候四个陷阱

1. **把 H1/H2 当定义**：它们是**假设**，必须在定理陈述里写明「若 H1、H2 成立」。
2. **忘记 A3**：`dΔ_1/dp_1 ≤ 0` 只说明「随 p₁ 减」，还要 A3 才能说「随 γ 减」。
3. **反例越界**：`p_i ≡ θ` 违反了 A2，说清它证的是什么。
4. **硬证 k ≥ 2**：写「猜想 + 数值支持」比写一个错证明强一百倍。
